Tata GenAI Powered Data Analytics Simulation

This repository contains my completed work from the GenAI Powered Data Analytics Job Simulation offered by Tata iQ in collaboration with Forage.

🚀 Overview

In this virtual simulation, I acted as an AI and Analytics Consultant for Geldium, a fictional financial services firm. The simulation focused on designing AI-driven solutions to predict and manage customer delinquency in the financial services sector.

The goal was to leverage data and GenAI tools to:

Explore and interpret customer data
Identify key risk indicators
Propose a predictive modeling framework
Design targeted business interventions
Build a responsible, autonomous AI-powered collections strategy
